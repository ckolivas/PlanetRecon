# Archived input compatibility

`compatibility.json` is a read-only bridge to this exact input family. The full
package source hash was reproduced from Git commit `84cde4e`; every listed
simulation/validation dependency remains byte-identical. The original manifest
and certificates are preserved. Reconstruction code may change independently,
with a separate study identity and new qualification. This is not a certificate
for new data, a changed simulator, a new likelihood or a new solver.
